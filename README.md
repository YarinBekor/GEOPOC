# GEOPOC - World of Circles

A comprehensive web application exploring the mathematical beauty and whimsical world of circles, built with Node.js and Express.

## About

World of Circles is an educational and entertaining website featuring:
- Mathematical properties and formulas of circles
- Real-world applications across engineering, science, and arts
- Historical significance and symbolism
- **The Circles Dynasty** - A creative royal lineage of circle characters
- Elaborate ceremonies and traditions celebrating circular perfection
- Visual gallery showcasing circles in all forms

## Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

## Running the Application

Start the server:
```bash
npm start
```

The application will be available at `http://localhost:3000`

## Features

### Pages

1. **Home** - Introduction to the World of Circles
2. **About Circles** - History, parts, natural occurrences, and symbolism
3. **Properties** - Mathematical formulas, equations, and geometric properties
4. **Applications** - Real-world uses in technology, architecture, science, and daily life
5. **The Circles Dynasty** - Royal lineage including King Circumfero, Queen Arealia, and their court
6. **Ceremonies & Traditions** - Festivals, rituals, and celebrations of the circular realm
7. **Gallery** - Visual showcase of circles by size, color, and function

## Technology Stack

- **Backend**: Node.js with Express 5.1.0
- **Template Engine**: EJS
- **Styling**: Custom CSS with gradients and responsive design
- **Architecture**: MVC pattern with partials for reusable components
